## 🎨 Cambiar Colores (2 minutos)

**Archivo:** `src/styles/global.css`

Busca y cambia:
```css
:root {
  --primary-dark: #2d5016;    ← Cambiar este
  --accent-beige: #d4c4a8;    ← Y este
  /* ... más variables */
}
```

Guarda y verás los cambios automáticamente.
